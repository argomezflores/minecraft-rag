TITLE: Key (April Fools' joke)
CATEGORY: Items

Keys are joke items only present in Java Edition 3D Shareware v1.34. There are three different keys: red, yellow, and blue.

Obtaining
Mobs
ColorDropped byRed YellowBlue

Cheat codes
These keys are also obtainable by typing the cheat code "IDKFA", not necessarily in the chat.

Natural generation

Fishing
Blue keys are obtainable through fishing, with a 0.6% chance per attempt.

Data values
ID

Trivia
32px A key with a similar appearance is present in The Europa Arcology Incident, a game made by Notch in 2009.
These keys and their cheat code are likely a reference to the original Doom game.
