A server provides a world for players to play multiplayer with others over the  or a  without the requirement for one player to be active in the world. Players can connect to a server from their game client in the server list, and they can host servers using the free server software or Minecraft Realms.

Variants

The default server software (server.jar  and BDS ) provides a stable environment for players to play a multiplayer game. It is provided free of charge by Mojang Studios for Windows, macOS, and Linux systems. Players can join these servers using the address and port from the in-game server list, except on consoles.
Minecraft Realms provides a multiplayer server which is always online. They are provided by Mojang Studios as a paid subscription-based server hosting service. In order to let other players join for free, the subscription owner can invite them and manage members. Realms also provides additional features, such as automatic world backups, in-game server and world management, and many extra features.
Realms are limited in player slots. In addition to the owner, a Realms server can only provide up to 10 players (Realms Plus and Java Realms) or 2 players (Realms Core) playing simultaneously in a multiplayer game, though an infinite number of players can be invited.
In Bedrock Edition, the server list provides a default set of featured servers promoted by Mojang Studios, that are always accessible from any device. In addition to this, Mojang Studios sometimes hosts in-game live events as servers accessible in-game.
The Official Minecraft Server List includes addresses of verified external Minecraft servers that can be added to the game, except on consoles.

Archetypes

Multiple archetypes of Minecraft multiplayer servers exist, distinguished by the unique gameplay features, rules, and societal structures that they implement. Each server is unique from the others, and often, the line between archetypes is blurred or indistinguishable. Many special types of servers rely on the use of map editors or the Creative game mode to build custom maps, and some use modded server software to provide additional features outside the vanilla experience. Some of these servers are heavily competitive, involving player versus player (PvP) and unique gameplay aspects of ; however, some simply followed the base vanilla survival experience.

Common archetypes found in Minecraft servers may include:

Management

Servers are generally managed by administrators and operators. The administrator is the host of the server, with access to the server logging, files, and server commands. Operators are players who joined the server with access to commands, player permissions, and game settings. Operators can also kick players from the world.

Features of a Minecraft server, such as the server's address, port, message of the day (MOTD), and others, can be configured on server.properties file, which contains key-value pairs that enable or disable such features. It is located under the server's working directory, alongside other resources. By default, the server listens to all  on  TCP port or  UDP port.

Servers do not strictly require access to Minecraft online services, and can be played on an isolated local network without  connection. Servers use Minecraft online services to fetch player skins and verify genuine Minecraft accounts, which prevents hackers and griefers from using false names while on such a server. This feature can be enabled or disabled by setting  in the server.properties.

On a server, multiple worlds can be stored; in server.properties can be specified which world is actively hosted. Servers can also have resource and behavior packs, as well as a Bedrock Editor project to join from the Editor.

Whitelist
The whitelist or allowlist is a feature provided by the server that allows and blocks specific players from joining the server. It works by checking the UUID or XUID of the players who who join the server; if it doesn't match, the player cannot join. Its configured in the  or  file inside the server's working directory, and can be activated by setting  or  server property. It is enabled by default.

Each entry in  or  is a JSON object identifying which players the server should allow access.

As well as manually editing the file, the / command can also be used by operators. When editing the file manually while the server is running, the command  needs to be used for the changes to take effect.

In Java Edition, server operators can always connect when the whitelist is active, even if their UUIDs do not appear in the whitelist. This differs from Bedrock Edition, where players must be whitelisted regardless of operator status.

Disconnect messages
Disconnect messages are texts that are displayed when an operator kicks the player or the player has issues connecting to the server.

Java Edition
Server or client errors
End Of Stream (Client message) – The server has stopped sending data to the client.
Internal Server Error:java.net.Minecraft (...) – The server is sending unknown information to the client. If the server is modded, this usually happens when a client with an outdated mod tries to join the server with the updated mod.
Timed Out – The client has lost connection to the server, likely due to disconnecting from the internet or having Minecraft features blocked by a firewall.
Internal exception: java.io.IOException: Received string length longer than the maximum allowed  – A chat message that the client sent to the server exceeded the maximum character limit (> 256).
Internal Server Error – The server generated an exception when handling the client's request.
Illegal characters in chat – The client was denied sending certain characters, such as the "§" .
Kicked for spamming (disconnect.spam) – The client is sending chat messages too quickly.
Read timed out – The server can't find the client's connection. This usually happens when the client has a slow Internet connection.
Bad login – The client is running in offline mode and can't connect to an authenticated server.
Out of memory! – This happens when the client or server cannot assign more memory to the game. This can be checked on the debug screen. It also happens if one traveled past X/Z: ±34,359,738,368 in Beta 1.7.3 or lower (see Far Lands).
Flying is not enabled on this server – The client tried to fly for longer than 5 seconds in Survival or Adventure mode, usually enabled by mods.
Attempting to attack an invalid entity – This happens when the client tries to hit either themselves, or an entity that can't normally be attacked (e.g. arrow, egg, ender pearl, trident). This is usually possible through mods.
Illegal stance – This happens when the client's position is extremely high on the sky or low on the void.
Illegal position – The client is beyond X/Z: ±30,000,000 (or ±32,000,000 in 1.6.4 and lower).
