⛏️ Minecraft Wiki Assistant

Un asistente RAG (Retrieval-Augmented Generation) construido en Python con FastAPI, ChromaDB y Claude. Responde preguntas usando el corpus oficial de minecraft.wiki (licencia CC BY-SA).

Cómo funciona:
  1. Tu pregunta se convierte en un vector semántico (embedding).
  2. Se buscan los artículos más relevantes en la base vectorial (ChromaDB).
  3. Esos fragmentos se pasan a Claude como contexto para generar la respuesta.
  4. La respuesta incluye citas linkeadas a la wiki original.

Abre el chat en la esquina inferior derecha 👉

Preguntas de ejemplo:

  • ¿Cómo se craftea un Beacon?
  • ¿Qué necesito para hacer un portal al Nether?
  • ¿Qué mob dropea diamantes?
  • ¿Cómo funciona la encantación Fortune?
  • ¿Cuáles son todos los materiales necesarios para brewing?

⚙️ Este widget también existe como bot de Mineflayer que responde directamente en el chat de Minecraft con el comando !rag <pregunta>.
